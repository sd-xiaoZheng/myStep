【核心设计理念】
一张巨大而朦胧的手账墙面。留言不再是果冻质感的便签，而是一张张轻薄微黄的
"手账纸页"——浅淡的田字格纹理、略带毛边的纸质触感。没有胶带，每张纸如同
被无形微风轻轻托在墙上。

风是隐形的。你看不到它。但纸张会出卖它的行踪——它们时而微微掀起一角，
时而整张纸轻轻漂移，时而又轻柔落下。风在屏幕四周随机生成，从不同方向
拂过，路径不可预测，让整面墙始终处于一种"安股风吹过多张纸静的呼吸"之中。用户能感受到
自然的、不重复的生动气息。

================================================================================

【一、强制横屏 + 沉浸式全屏】

  - 进入页面立即锁定为横屏（LandscapeLeft / LandscapeRight 均支持）
  - 状态栏和导航栏采用透明叠加（overlay），让手账墙撑满整个屏幕
  - 无任何生硬的系统边框感，营造"无限延伸的墙面"氛围
  - 离开页面时解除横屏锁定

【二、视觉设计详述】

--------------------------------------------------------------------------------
2.1 画布背景
--------------------------------------------------------------------------------

  三层叠加结构（从下到上）：

  第一层 - 远景底图：
      应用内置 5-8 张高清暖色调背景图（旧纸纹理、软木墙面、亚麻布纹、
      复古皮革、水彩晕染等），进入页面时随机选一张。以 cover 模式铺满。

  第二层 - 雾化柔光层：
      在底图之上叠加一层高斯模糊（blur 8-12px）+ 奶白色半透明遮罩
      rgba(255,252,245,0.55)，营造出"透过柔光看手账墙"的朦胧温暖感。

  第三层 - 装饰层（可选，非常淡）：
      屏幕四角有极淡的暗角效果（vignette），让视觉重心自然聚拢到中央。
      偶尔有极细的纸张纤维纹理 overlay，透明度约 3%-5%，几乎不可见但
      增加了纸质温度。

--------------------------------------------------------------------------------
2.2 留言纸张（取代原先的便签果冻）
--------------------------------------------------------------------------------

  单张纸的基本形态：
      - 尺寸：宽约 180-210pt，高约 130-180pt（内容多时自适应增高）
      - 形状：微圆角矩形（圆角约 4-6pt），保留纸张的方正感但不过于锋利
      - 底色：微黄色调，模拟真实纸张，如 #FFFDF5 ~ #FFF8E7 区间，
              每张纸有细微色差（±2% 随机偏差），杜绝工业化的统一感
      - 透明度：整体约 0.92，微微透出下方背景

  田字格纹理：
      - 纸张上铺有浅淡的田字格/方格线（类似手账本内页）
      - 线条颜色：极淡的蓝灰色或灰绿色，如 rgba(180,190,200,0.18)
      - 格子大小：约 14-16pt 见方
      - 线条宽度：约 0.5pt，绝不可粗重
      - 线条在纸张边缘约 8pt 处停止（有内边距）
      - 纸张上部约 20% 区域留白，模拟手账的标题区

  纸张边缘质感：
      - 极轻微的锯齿/毛边效果（shadow 扩散模拟或 SVG filter feTurbulence），
        让边缘不是完美的直线，带有微小的不规则感
      - 可选：右侧边缘有极浅的阴影（模拟纸张翘起），透明度约 10%

  纸张阴影：
      - 柔和投影，偏移 (1.5pt, 2pt)，模糊半径约 10-14pt，
        颜色 rgba(80,60,30,0.12)
      - 不是生硬的 drop shadow，而是类似真实纸张浮在墙上的轻盈投影

  纸张上的内容布局（从上到下）：
      ┌─────────────────────────────┐
      │  [头像 28pt]  网名（加粗）  │  ← 标题区，约 32pt 高
      │─────────────────────────────│  ← 淡色分隔（田字格线条自然分隔）
      │                             │
      │  留言正文内容...             │  ← 正文区，默认字号 14pt
      │  自动换行，行间距 1.4       │     文字颜色 #4A3728（深棕）
      │                             │
      │                             │
      │             15:30 2025-05-01│  ← 时间戳，右下对齐，11pt，浅棕
      └─────────────────────────────┘

  纸张颜色变体（6种，微妙区分，都偏暖纸色系）：
      1) 象牙白  #FFFDF5  - 最白，如新纸
      2) 米白    #FFFAF0  - 偏暖白
      3) 蛋壳色  #FFF8E7  - 微黄
      4) 浅奶色  #FFF5E0  - 更暖
      5) 旧纸色  #FDF5E6  - 微微做旧
      6) 茶渍色  #FBF0D9  - 最黄，如翻过多页的手账
      所有底色都带 0.90-0.94 的透明度，不会过实。

【三、风系统 —— 核心动态效果】

这是本次设计最重要的差异化功能。风完全不可见，但它持续地、随机地影响着
墙上每一张纸。

--------------------------------------------------------------------------------
3.1 风的基本模型
--------------------------------------------------------------------------------

  概念模型（非可视化）：
      想象屏幕四周有若干"风源点"，这些点不可见，随机分布在屏幕四边（上、
      下、左、右）的外侧。每个风源点按独立的随机节律"呼气"——强度在
      0 到某个最大值之间以正弦波或其他不规则波形变化。

  风的参数：
      - 方向：从 0°到 360° 中随机取值，但偏向于从左→右或右→左（横屏的
              自然风感），上/下方向的风较少
      - 强度：0.0 ~ 1.0，随时间缓慢变化（周期 3~12 秒不等）
      - 持续时长：一阵风持续 4~15 秒，然后衰减
      - 间隔：两阵风之间间隔 2~8 秒（随机）
      - 同时可能有多股风（最多 2-3 股）从不同方向吹来

--------------------------------------------------------------------------------
3.2 风对纸张的作用效果
--------------------------------------------------------------------------------

  纸张对风的响应是分层的、有轻重缓急的：

  A) 微弱风（强度 0.0 ~ 0.25）——"呼吸"
      - 纸张微微上下浮动，Y 轴偏移约 ±2pt
      - 旋转角度在 ±1° 之间缓慢摆动
      - 所有纸张都以各自略微不同的相位摆动（毫无整齐感）
      - 这是"无风"时的常态，像人在安静呼吸
      - 持续时间：连续不断

  B) 轻风（强度 0.25 ~ 0.5）——"轻拂"
      - 纸张在基础位置上叠加一个方向性的偏移
      - 风从左来 → 纸张右侧微微翘起（绕左侧的 Y 轴旋转约 2°-5°）
      - 纸张整体朝风向偏移约 3-8pt
      - 纸张的投影随之偏移和扩散（模拟纸与墙的距离增大）
      - 风经过后纸张缓慢恢复到原位（回弹动画 1-2 秒）

  C) 中风（强度 0.5 ~ 0.75）——"掀动"
      - 靠近风源（屏幕边缘）的纸张先响应，远离的纸张延后约 0.3-0.8 秒
      - 纸张的一个角明显掀起（绕两条轴的复合旋转），掀起角约 5°-12°
      - 纸张边缘可能出现快速的微小颤动（频率约 8-12hz，幅度约 1pt）
      - 纸张整体沿风向位移约 10-20pt
      - 风过后用 Spring 动画回弹（damping 0.55，stiffness 120），
        纸张会有 2-3 次明显振荡才静止

  D) 强风（强度 0.75 ~ 1.0）——"飞舞"（极少触发，约每 30-60 秒一次）
      - 受影响的纸张一角大幅掀起（15°-25°），仿佛要被吹离墙面
      - 纸张沿风向位移约 25-40pt
      - 多张纸呈"波浪"效果——从近风源处向远处，纸张逐一掀动再落下
        （cascade / stagger 延迟，每张间隔约 0.15 秒）
      - 风过后，纸张以更强的弹簧动画回弹，
        高频小幅振荡（damping 0.4，stiffness 180），持续约 1.5 秒
      - 强风后通常跟一段较长的"微弱风"平静期（6-15 秒）

  风的方向性传导：
      - 同一股风吹过多张纸时，根据纸张距风源的距离产生延迟
      - 近风源的纸张先动 → 中间的纸张晚 0.2 秒 → 远处的纸张晚 0.5 秒
      - 形成自然的"风吹麦浪"效果
      - 每张纸对风有微小的随机响应差异（±15%），避免机械感

  纸与纸之间的相互影响（可选增强）：
      - 当一张纸被强风掀起后落下，离它很近的其他纸也会微微颤动
      - 模拟物理世界中的"连带震动"，幅度微小（约 0.5pt）

--------------------------------------------------------------------------------
3.3 风的周期性
--------------------------------------------------------------------------------

  风的状态机：

      平静期(8-20s) → 轻风(4-10s) → 平静或中风(3-8s) → 平静期...
                                                ↓
                                           偶尔强风(2-4s) → 长平静期

  平静期不是完全静止——"呼吸"效果始终存在。
  绝大多数时间（约 70%）墙面处于"呼吸+轻风"的状态，有轻微的生气。
  中风和强风是调味剂，偶尔出现带来惊喜。

  同一时刻至多有 2-3 股不同方向的风共存，它们在空间中自然交叉，
  交汇处的纸张受到多股风的合力影响。

【四、纸张交互（手势）】

--------------------------------------------------------------------------------
4.1 点击 —— 置顶查看
--------------------------------------------------------------------------------
  - 轻点纸张 → 该纸张 scale 到 1.08（轻微弹跳），z-index 升至最高
  - 同时纸张暂时脱离风的影响（风继续作用于其他纸，但这张保持稳定），
    让用户可以安稳阅读内容
  - 3 秒无操作后自动恢复受风影响
  - 若纸张原本被风掀起一角，点击后先平复再放大

--------------------------------------------------------------------------------
4.2 长按 —— 拖拽
--------------------------------------------------------------------------------
  - 长按约 0.35 秒，触发轻微触觉反馈
  - 纸张从墙上"拿起"——阴影加深（离墙更远），scale 略微放大至 1.06
  - 拖拽过程中纸张暂时不受风影响
  - 手指移动时纸张跟随，使用 Spring 连接（不是死板的 1:1 跟随，
    而是有约 0.1 秒的延迟跟随，模拟纸张的惯性质量感）
  - 松手后纸张以 Spring 动画回弹到松手位置
  - 松手后该纸张重新受风影响
  - 边界约束：纸张中心不可超出画布边界（四周留 15pt 安全边距）

--------------------------------------------------------------------------------
4.3 双击 —— 展开详情
--------------------------------------------------------------------------------
  - 双击纸张 → 纸张展开至居中全宽的 65%，高度自适应
  - 展开动画约 0.4 秒（Spring），其他纸张轻微向四周让开（模糊化）
  - 展开状态下可滚动查看完整内容，背景出现半透明暗色遮罩
  - 再次双击或点击遮罩 → 纸张缩回原位，恢复风的影响
  - 展开状态下风不作用于该纸张

--------------------------------------------------------------------------------
4.4 向上轻扫 —— 删除（仅限自己发的留言）
--------------------------------------------------------------------------------
  - 在纸张上向上快速滑动 → 纸张模拟被风吹走的效果：
    纸张绕随机轴旋转并逐渐透明，沿扫动方向飞出屏幕
  - 飞出动画约 0.6 秒
  - 飞出前弹出确认提示（HUD 样式）"确定删除这条留言吗？"
  - 取消时纸张以回弹动画返回原位

【五、输入面板（新增留言）】

  （与 v1.0 基本一致，以下是调整和补充）

  - 呼出方式：右下角 FAB 按钮（羽毛笔图标），点击后底部面板滑入
  - 面板背景：浅纸纹理（与手账主题一致），半透明毛玻璃
  - 头像选择：圆角方形（4pt），与纸张的方正感呼应，不再是圆形
  - 输入框：内部带有极淡的田字格纹理线，与纸张风格统一
  - 网名输入：单行，Max 16 字符
  - 留言输入：多行，Max 500 字符，右上角实时计数
  - 提交按钮：暖棕色系（与纸张暖色调和谐），圆角 6pt
  - 提交后新纸张以"被风从面板吹到墙上"的动画加入画布：
      纸张从面板位置旋转飘出，沿一条略微弯曲的弧线（受"风"影响），
      飞向墙上的随机空位，到达后轻微弹跳静止，之后立即开始受风影响

================================================================================

【六、性能与渲染】

  - 风系统使用 CADisplayLink / VSync 驱动，60fps
  - 纸张数 < 30 时：全量渲染，每张纸独立接受风计算
  - 纸张数 30-80 时：对屏幕外的纸张降低风计算频率（每 3 帧算一次）
  - 纸张数 > 80 时：屏幕外纸张冻结风效果，仅屏幕内+边缘 30% 区域实时计算
  - 所有纸张的 transform 动画统一在一个 display link 中批量提交
  - 田字格纹理使用 tile 模式渲染（生成一张小纹理图后 repeat），
    不要每张纸实时绘制线条

================================================================================

【七、状态与边界】

  - 空状态：画布中央一张较大的手账纸缓缓漂浮（呼吸效果），
            上面手写体文字："写下第一行吧..."
  - 加载中：画布左上角一张小纸片微微颤动（像被微风拨弄）
  - 加载失败：中央纸上显示"风太大，把字吹散了..." + 重试按钮
  - 网络断开：不阻断当前页面，提交的留言进入本地队列，
              恢复网络后自动提交，纸张以半透明灰态表示"待同步"
  - 提交中：FAB 旋转（羽毛笔书写动画），面板内提交按钮 loading
