【总体概述】
这是一个"便签留言墙"应用页面。用户可以在一个具有毛玻璃模糊背景的画布上，
以彩色半透明便签纸的形式发布和查看留言。每条留言以随机位置、随机旋转角度
的便签纸呈现，用户可拖拽便签、点击置顶、查看留言详情。整个页面氛围温暖、
文艺，带有手作感。

进入App页面时，强制切换为横屏（Landscape）模式展示。

================================================================================

【一、页面布局结构（横屏）】

页面采用左右两栏布局（横屏比例约 7:3）：

┌──────────────────────────────────────────────────┬────────────┐
│                                                  │            │
│                                                  │  头像选择    │
│                                                  │  (可点击)    │
│              留言墙画布区域                         │            │
│         （便签随机分布，可交互）                      │  网名输入    │
│                                                  │            │
│                                                  │  留言输入    │
│                                                  │            │
│                                                  │  提交按钮    │
├──────────────────────────────────────────────────┴────────────┤
│                      底部装饰条 / 页面标题                        │
└───────────────────────────────────────────────────────────────┘

左侧（约70%宽度）：留言墙画布，所有便签在其中展示
右侧（约30%宽度）：输入面板，包含头像、网名、留言框、提交按钮

或者采用另一种布局——留言墙全屏作为背景，输入区域以底部弹出面板（Bottom Sheet）
的形式呈现，从底部上滑呼出。推荐此方案，因为能最大化便签的操作空间。

【二、核心功能清单】

--------------------------------------------------------------------------------
功能1：留言便签展示
--------------------------------------------------------------------------------

  - 每条留言以一张"便签纸"（Sticky Note）的形式展示在画布上
  - 便签纸尺寸：宽度约 200-220pt，最小高度约 150pt（根据内容自适应）
  - 便签纸在画布上的位置：随机分布（left: 10%~90%, top: 10%~90%），
    旋转角度随机（-25° ~ +25°），每条留言的初始位置各不相同
  - 便签纸颜色：6种颜色轮回，分别为
      浅粉色 rgba(255,182,193,0.85)
      暖橙色 rgba(255,166,77,0.85)
      矢车菊蓝 rgba(100,149,237,0.85)
      青绿色 rgba(72,209,204,0.85)
      草绿色 rgba(144,238,144,0.85)
      淡紫色 rgba(221,160,221,0.85)
    所有颜色带有 0.85 透明度，呈现轻盈半透明质感
  - 每张便签包含以下内容（从上到下）：
      a) 顶部胶带装饰：模拟真实便签上用胶带粘贴的效果，一条半透明白色矩形，
         覆盖在便签顶部居中位置，带有细微的条纹纹理
      b) 留言者信息行：圆形头像（直径约 28-30pt）+ 网名（加粗文字）
      c) 留言正文：普通字重的文字，字号约 15-16pt，自动换行
      d) 留言时间：右下角对齐，小号灰色文字，格式 yyyy-MM-dd HH:mm:ss
  - 便签纸的视觉效果：
      a) 圆角约 10-12pt
      b) 轻微阴影（偏移约 2pt，模糊约 12pt，颜色 rgba(0,0,0,0.15)）
      c) 内阴影在底部（模拟纸张厚度感）
      d) 左上到右下的对角线高光渐变（模拟光泽，rgba(255,255,255,0.4)→透明）
      e) 毛玻璃效果（backdrop-filter: blur，hover时启用约3px模糊）

--------------------------------------------------------------------------------
功能2：留言便签交互
--------------------------------------------------------------------------------

  2a. 拖拽移动（核心交互）
      - 用户手指长按便签（约 0.3 秒）后激活拖拽模式
      - 激活时给予触觉反馈（Haptic Feedback / 轻微震动）
      - 拖拽过程中便签略微放大（scale: 1.03），阴影加深，跟随手指移动
      - 拖拽边界限制：便签不可拖出画布区域（四边留约 5pt 边距）
      - 松手后便签停留在新位置，附带弹性动画（spring animation），
        便签会有轻微的惯性回弹效果
      - 拖拽过程中其他便签保持静止

  2b. 点击置顶（z-index 管理）
      - 点击任意便签时，该便签的 z-index 提升到最高（全局递增计数器）
      - 被点击的便签短暂轻微放大再恢复（弹跳动画，约 0.2 秒）
      - 该便签覆盖在其他便签之上

  2c. 双击/双指缩放
      - 双击便签：便签放大至 1.15 倍，内容完全可见，再次双击恢复
      - 放大状态下的便签不可拖拽，再次双击后恢复可拖拽状态
      - 双指捏合手势可以缩放便签大小（0.8x ~ 1.5x 范围）

  2d. 长按删除（可选，需确认是否有此需求）
      - 长按便签 1.5 秒以上，弹出确认删除对话框
      - 确认后便签以缩小+淡出动画消失

--------------------------------------------------------------------------------
功能3：留言输入与提交
--------------------------------------------------------------------------------

  3a. 输入面板形式
      - 以底部滑出面板（Bottom Sheet）呈现
      - 从屏幕底部向上滑动呼出，默认收起为一个小圆角悬浮按钮（FAB）
      - FAB按钮显示"+"或羽毛笔图标，位于屏幕右下角
      - 面板高度约占横屏高度的 45%~50%，带有模糊半透明背景
      - 面板顶部有拖拽手柄（drag handle），可下滑关闭

  3b. 头像选择
      - 显示当前选中的头像（圆形，直径约 48pt）
      - 点击头像触发轮播切换：从内置头像库中循环切换到下一个
      - 头像库为应用中预置的多个卡通/插画风格头像 PNG 图片
      - 切换动画：头像以翻牌效果（flip animation）切换，持续约 0.3 秒
      - 每次进入页面时随机预选一个头像

  3c. 网名输入
      - 文本输入框，placeholder："请输入您的网名"
      - 单行输入，最大字符数 20
      - 键盘类型：普通文本键盘
      - 获得焦点时边框高亮为暖橙色（#ffa500）

  3d. 留言内容输入
      - 多行文本输入框（textarea），placeholder："请输入您的留言"
      - 最大字符数 500，右下角显示当前字符数/500
      - 获得焦点时边框高亮为暖橙色（#ffa500）
      - 支持换行，自动高度调整（最高 4 行）

  3e. 提交按钮
      - 主色调按钮（蓝色 #409EFF），圆角，文字"发表留言"
      - 点击前校验：网名和留言均不可为空，为空时弹 Toast 提示"网名和留言内容不能为空"
      - 提交时按钮显示加载状态（loading spinner），防止重复提交
      - 提交成功：
          a) Toast 提示：后端返回的成功消息（如"您起的名字好美，我收录咯~"）
          b) 新便签从面板位置以动画飞入画布，落到随机位置并轻微弹跳
          c) 自动清空输入框
          d) 面板自动收起（下滑关闭）
      - 提交失败：
          a) Toast 提示错误信息
          b) 输入内容保留，不关闭面板
      - 提交数据格式：multipart/form-data，包含
          a) nickname: 网名字符串
          b) content: 留言内容字符串
          c) avatar: 当前选中的头像图片文件（作为文件上传）

--------------------------------------------------------------------------------
功能4：留言墙画布背景
--------------------------------------------------------------------------------

  4a. 背景图片
      - 应用内置多张高清艺术背景图（自然风景/星空/抽象），作为画布背景
      - 每次进入页面时随机选择一张作为背景
      - 背景以 cover 模式填充整个画布区域
      - 背景上覆盖一层模糊和半透明遮罩，形成毛玻璃效果：
          原始背景图 → blur(3px) → 叠加半透明白色遮罩 rgba(255,255,255,0.5)
          → 最终呈现朦胧柔和的背景

  4b. 背景切换（可选增强功能）
      - 画布右下角放置一个半透明的小图标按钮
      - 点击随机切换到下一张背景图
      - 切换动画：淡入淡出（crossfade），持续约 0.8 秒

--------------------------------------------------------------------------------
功能5：数据加载
--------------------------------------------------------------------------------

  5a. 初始加载
      - 页面进入时发起 GET 请求获取所有留言数据
      - 接口：GET /step/msgWall/getmsg
      - 加载过程中画布中央显示优雅的加载动画（如旋转的羽毛笔或便签纸飘落动画）
      - 数据加载完成后，每条留言被渲染为一张便签，随机分布在画布上
      - 如果加载失败，显示重试按钮和错误提示

  5b. 下拉刷新
      - 在画布区域下拉可触发刷新
      - 刷新动画：画布顶部出现自定义刷新指示器（如一张飘动的便签）
      - 刷新完成后新数据以动画方式插入

  5c. 自动刷新（可选）
      - 每 60 秒静默轮询一次，有新留言时以动画添加到画布

【三、动画与过渡效果详述】

  a) 页面进入动画
     - 整体页面从下方滑入（slide up + fade in），持续 0.5 秒
     - 便签逐个弹出（stagger animation），每张间隔约 0.08 秒
     - 弹出效果：从 scale(0.3) + opacity(0) → scale(1) + opacity(1)
       附带 overshoot（弹簧过冲），让人感觉便签"啪"地出现在墙上

  b) 便签拖拽释放动画
     - 使用 Spring 物理动画（damping ≈ 0.7, stiffness ≈ 150）
     - 便签回到稳定位置时带有微小振荡，模拟真实纸张的弹性

  c) 便签点击高亮
     - 0.15 秒内 scale 从 1.0 → 1.06 → 1.02 → 1.0
     - shadow 短暂加深

  d) 底部面板滑入滑出
     - Spring 动画，damping ≈ 0.8
     - 背景遮罩同步淡入淡出（opacity 0 ↔ 0.5）
     - 可中断手势：用户可以在动画过程中用手势反向滑动取消

  e) 新留言飞入动画
     - 从提交按钮位置出发，抛物线轨迹飞向画布中的随机落点
     - 到达落点后弹性弹跳 2-3 次后静止
     - 持续时间约 0.8 秒

  f) 页面转场
     - 进入此页面：从右向左推入（push）
     - 离开此页面：从左向右推出（pop）
     - 或使用共享元素转场（如果有前一个页面的关联元素）

【四、横屏强制与适配要求】

  4a. 强制横屏
      - 进入该页面时，通过系统API锁定屏幕方向为横屏（Landscape）
      - 支持左右两个方向的横屏（LandscapeLeft 和 LandscapeRight）
      - 离开该页面时恢复屏幕方向为默认（由系统自动管理）

  4b. 安全区域适配
      - 正确处理 iPhone 的 Safe Area / Android 的 Display Cutout
      - 画布和输入面板完全在安全区域内
      - 刘海/挖孔区域不遮挡任何交互元素

  4c. 横屏比例适配
      - 支持 16:9、19.5:9、20:9 等不同横屏比例
      - 画布区域自动填充可用空间
      - 便签大小在不同屏幕密度下保持一致的物理尺寸（dp/pt）

【五、技术实现建议】

  5a. 手势处理
      - 使用平台原生手势系统（iOS: UIPanGestureRecognizer / SwiftUI DragGesture；
        Android: GestureDetector / Compose pointerInput）
      - 便签的 Tap（点击）、LongPress（长按拖拽）、DoubleTap（双击放大）手势清晰区分
      - 底部面板使用原生 Sheet/DraggableBottomSheet 组件

  5b. 动画框架
      - iOS: SwiftUI Animation / UIViewPropertyAnimator / UIKit Dynamics
      - Android: Jetpack Compose Animation / MotionLayout
      - 优先使用声明式动画（更易维护）

  5c. 性能
      - 便签数量较多时（>50条），使用懒加载/虚拟化渲染
      - 画布背景图片做适当压缩和缓存
      - 拖拽时使用 GPU 加速（transform），避免触发 layout

  5d. 网络层
      - 使用 Retrofit（Android）/ Alamofire 或 URLSession（iOS）
      - 图片加载使用 Glide/Coil（Android）/ Kingfisher/SDWebImage（iOS）
      - 请求超时设为 15 秒
      - 无网络时显示离线提示，使用本地缓存数据展示

【六、边界情况与状态处理】

  - 空状态：无留言时，画布中央显示优雅的空状态插画和文字"留下第一张便签吧~"
  - 加载失败：显示重试按钮 + "网络开小差了，请重试"
  - 提交失败：Toast 提示，输入内容不清除
  - 提交中：按钮显示 loading，禁止重复点击
  - 快速拖拽：使用 requestAnimationFrame / VSync 节流，避免丢帧
  - 多指同时拖拽：同一时间只允许拖拽一张便签，其他手指操作被忽略
  - 横屏键盘弹起：输入面板自动上移，不被键盘遮挡
