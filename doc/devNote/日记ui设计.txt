 # MyStep 日记模块 — 移动端 UI 设计需求书

 > **项目定位：** MyStep 是一套个人成长足迹记录系统，帮助用户记录生活点滴、管理个人相册、撰写日记、留言互动。
 > **当前任务：** 为日记模块设计适配手机端的 UI 界面。现有桌面端页面已完成功能，但移动端体验不理想，需要重新设计移动端 UI。

 ---

 ## 一、项目背景

 ### 1.1 项目信息

 | 项目 | 说明 |
 |------|------|
 | 项目名称 | MyStep - 我的成长足迹记录系统 |
 | 项目性质 | 个人成长记录 / 私人日记应用 |
 | 项目风格 | 温润、柔和、治愈系，以低饱和渐变色调营造"记忆的温润感" |
 | 技术栈 | Spring Boot 3.2.4 + Vue2 + Element UI + PostgreSQL 17 |
 | 目标用户 | 个人用户，追求记录和反思自我成长 |

 ### 1.2 设计风格关键词

 - **温润柔和** — 低饱和度色彩，渐变过渡自然
 - **治愈系** — 让人感到安静、放松、有安全感的视觉体验
 - **书写感** — 营造日记/手账的氛围，有温度而非冰冷
 - **简洁克制** — 信息密度适中，不堆砌，给内容留白空间
 - **个人化** — 用户可以选择颜色、图标来表达自己的情绪

 ### 1.3 已有配色参考

 桌面端使用渐变背景：
 ```
 background: linear-gradient(135deg,
   rgba(180, 170, 190, 0.85),
   rgba(220, 200, 190, 0.85),
   rgba(245, 235, 220, 0.85));
 ```
 即：浅紫灰 → 柔粉棕 → 暖米黄，模拟"泛黄纸张"般的记忆温度。

 主色调：#3498db（蓝色），强调色：#8e44ad（紫色），成功色：#4CAF50（绿色）。

 ---

 ## 二、日记模块核心功能概览

 日记模块有 **4 个主要页面**：

 1. **日记首页（diaryHome）** — 总览仪表盘，快速入口
 2. **日记编辑页（diaryCreate）** — 新建/编辑日记
 3. **日记列表页（diaryList）** — 搜索、筛选、浏览日记
 4. **日记管理页（diaryListManage）** — 后台管理表格（管理端功能，移动端可暂不考虑）

 ---

 ## 四、四个核心页面详细需求

 ### 4.1 日记首页（diaryHome）

 **页面定位：** 日记模块的总览仪表盘，用户打开后首先看到，提供快速入口和概览信息。

 **信息架构（从上到下）：**

 #### 区块 1 — 顶部欢迎栏
 - 问候语：「> 留下今日点滴 <」（风格化装饰）
 - 当前日期：「今天是 2026 年 X 月 X 日」
 - 设计建议：简洁大气，居中，字号适中

 #### 区块 2 — 快速新建卡片
 - 大按钮「+ 新建日记」（跳转编辑页）
 - 次按钮「心情日记」（快捷入口，可预设心情）
 - 配一个小编辑图标

 #### 区块 3 — 今日待办卡片
 - 标题「今日待办」+ 添加按钮（+号）
 - 待办列表项：checkbox + 文字 + 删除按钮
 - 底部「查看所有待办 →」链接

 #### 区块 4 — 本月统计卡片
 - 标题「本月统计」
 - 大数字展示：本月日记篇数
 - 大数字展示：连续写作天数

 #### 区块 5 — 日记分类模块入口（4 个卡片横滑或网格）
 - 每个卡片：图标 + 名称 + 简短描述 + 该类型篇数 + 箭头
 - 4 种分类：日记（记录日常）、记忆（写下回忆）、阶段总结（回顾总结）、畅想（未来规划）

 #### 区块 6 — 最新日记列表
 - 标题「最新日记」+「查看全部 →」
 - 日记卡片列表（2~N篇预览）：
   - 日记标题
   - 正文摘要（截断 2-3 行）
   - 元信息行：写作日期时间 + 类型标签 + 相对时间（5 分钟前/1 天前）

 **移动端适配特别建议：**
 - 区块 2、3、4 在桌面端是水平三列布局，移动端建议改为垂直堆叠或横滑卡片
 - 统计数字要大且醒目
 - 底部导航栏固定，方便随时切换

 ---

 ### 4.2 日记编辑/新建页（diaryCreate）

 **页面定位：** 用户写日记的核心页面，表单型页面，字段较多。

 **信息架构（从上到下）：**

 #### 步骤 0 — 页面框架
 - 顶部导航：面包屑「首页 > 新建日记」或返回箭头
 - 页面标题：「> 新建日记 <」
 - 整体容器有圆角卡片风格，边框颜色跟随用户选择的 `color` 字段

 #### 步骤 1 — 记忆日期（memory_time）
 - 类型：日期选择器（DatePicker）
 - 必填
 - 说明：这是用户记忆中的日期，不一定是今天的日期

 #### 步骤 2 — 记忆颜色（color）
 - 类型：颜色选择器
 - 默认 #3498db
 - 显示一个圆形颜色预览块 + 十六进制色值文字
 - 点击弹出系统取色器

 #### 步骤 3 — 天气选择（weather_id）
 - 类型：Tab 按钮组，单选
 - 15 个天气选项，每个显示为一个可点击的标签按钮
 - 选中态高亮（蓝色）
 - 可配合天气图标展示

 #### 步骤 4 — 心情选择（mood_id）
 - 类型：Tab 按钮组，单选
 - 8 个心情选项，同上交互
 - 可配合心情图标展示

 #### 步骤 5 — 类型选择（type_id）
 - 类型：Tab 按钮组，单选
 - 7 个类型选项：感想、日记、记忆、畅想、阶段总结、情绪、故事
 - 必选

 #### 步骤 6 — 标签选择（tag_ids）
 - 类型：圆角标签按钮组，**多选**，最多 3 个
 - 约 71 个标签，建议分组折叠展示或搜索
 - 选中态高亮（紫色）
 - **队列式选择：** 选满 3 个后，再选第 4 个时自动移除第 1 个
 - 每个标签用其自身的 color 展示

 #### 步骤 7 — 标题输入
 - 类型：单行文本输入
 - 占位符：「请输入日记标题...」
 - 必填

 #### 步骤 8 — 正文输入
 - 类型：多行文本区（Textarea）
 - 占位符：「记录今天发生的事情...」
 - 最小高度约 200px，可拉伸
 - 必填
 - 底部显示正文字数统计：「正文字数：XX 字」

 #### 步骤 9 — 配图上传
 - 类型：图片上传
 - 最多 3 张
 - 按钮「选择图片」+ 提示「最多上传 3 张」
 - 上传后显示方形缩略图预览（80x80），右上角有删除按钮（红色 ×）
 - 支持 jpeg/png/jpg 格式

 #### 步骤 10 — 底部操作按钮
 - 「取消」按钮（灰色，返回上一页）
 - 「保存日记」按钮（蓝色渐变，主操作）

 **移动端适配特别建议：**
 - 表单字段很多，建议分步骤（Step）或使用折叠面板，减少单屏信息量
 - Tab 按钮组在移动端可改为横滑选择器
 - 标签选择在移动端可用底部弹出面板（Bottom Sheet）呈现
 - 颜色选择器可用预设色块快速选择
 - 键盘弹出时输入区域应自动调整，避免被遮挡
 - 图片上传在移动端可调用相机拍照

 ---

 ### 4.3 日记列表/搜索页（diaryList）

 **页面定位：** 日记浏览与搜索页面，用户可以按多种条件筛选日记。

 **信息架构（从上到下）：**

 #### 区块 1 — 顶部操作栏
 - **日期范围选择器：** 开始日期 ~ 结束日期
 - **快捷时间按钮组：** 全部 / 今年 / 本月 / 近一周
 - **搜索框 ×2：** 搜索标题 + 搜索内容（支持回车搜索）
 - **搜索按钮 + 清除筛选按钮**
 - **「+ 新建日记」按钮**

 #### 区块 2 — 数据统计区（2 个卡片）
 - **心情分布卡片：**
   - 标题「心情分布」
   - 列出各种心情 + 百分比（如：😊 开心 45%）
   - 带简单的进度条或饼图
 - **本年活跃度卡片：**
   - 标题「本年活跃度」
   - 12 个月份的柱状图（1月~12月）
   - 每根柱子高度反映当月日记篇数
   - 柱子可点击（点击后筛选该月日记）
   - 柱子上方/下方显示月份和篇数

 #### 区块 3 — 筛选气泡行
 - **已选筛选项：** 以彩色气泡形式展示在标题旁
   - 每个气泡：名称 + hover 显示 × 删除按钮
   - 已选项再次点击会闪烁提示
   - 「清除」按钮一键清空
 - **可选筛选项行：** 自动横向滚动的气泡
   - 将 weather/mood/type/tag 所有选项混合随机排列
   - 未选中的气泡点击后加入已选
   - 鼠标悬停暂停滚动
   - 选中的气泡变蓝色高亮

 #### 区块 4 — 日记卡片网格
 - 标题：「我的日记」+ 结果计数「共找到 X 篇日记」
 - 卡片网格布局（桌面端 3 列 → 移动端建议 1 列）
 - 每个日记卡片：
   - **标题**（支持搜索关键词高亮，用 `<em>` 标签标红）
   - **日期**（写作时间）
   - **正文预览**（截断 2-3 行，支持关键词高亮）
   - **元信息行：**
     - 天气名称（橙色文字）
     - 类型名称（蓝色文字）
     - 标签列表（彩色圆角标签，每个标签用其自身 color）
 - 卡片带有淡入上浮动画（staggered animation）
 - hover 时卡片上浮 + 背景变亮

 **移动端适配特别建议：**
 - 操作栏在移动端非常拥挤，建议分层折叠：搜索框可收起到搜索图标里，点击展开
 - 快捷时间按钮可改为下拉选择
 - 统计区卡片堆叠展示
 - 活跃度柱状图在手机屏幕可改为横向滚动
 - 筛选气泡行保留横滑交互（天然适配手机触摸滑动）
 - 日记卡片改为单列列表，支持下拉刷新和上拉加载更多
 - 每张卡片占满屏幕宽度，图片优先展示

 ## 五、交互细节补充

 ### 5.1 标签队列选择逻辑
 - 用户最多选 3 个标签
 - 当已有 3 个标签时再点新的，自动移除最早选中的那个（FIFO 队列）
 - 点击已选中的标签则取消选中

 ### 5.2 搜索体验
 - 支持按标题搜索 + 按内容搜索（两个独立输入框）
 - 支持按日期范围搜索
 - 支持按天气/心情/类型/标签组合筛选
 - 搜索结果中关键词高亮（`<em>` 标签）
 - 筛选条件通过 Elasticsearch 查询，支持全文检索

 ### 5.3 图片处理
 - 新建日记时上传图片 → 后端自动转 WebP 格式并压缩
 - 图片按年月分目录存储
 - 编辑日记时可替换/删除已有图片

 ### 5.4 自动填充字段
 - 写作时间：系统自动设为当前时间
 - 作者信息：自动获取当前登录用户
 - 发生地址：根据 IP 自动解析（如"广东深圳"或"未知内网IP"）

 ### 5.5 数据同步
 - 日记数据双写：PostgreSQL（主存储）+ Elasticsearch（搜索索引）
 - 编辑/删除时同步更新 ES

 ## 六、移动端设计总体要求

 ### 6.1 布局
 - 以 375px（iPhone 6/7/8）为基准设计宽度
 - 适配刘海屏/挖孔屏（Safe Area）
 - 底部留出 Home Indicator 安全区
 - 卡片圆角 12-16px，营造柔和触感
 - 卡片间距 12-16px

 ### 6.2 导航
 - 日记首页和日记列表页建议使用底部 Tab 导航或顶部 Tab
 - 编辑页为全屏沉浸式，顶部仅保留返回按钮和保存按钮
 - 支持手势返回（iOS 左滑）

 ### 6.3 字体
 - 标题字号 18-20px，正文字号 15-16px，辅助文字 12-13px
 - 中文优先使用系统默认字体（PingFang SC / Microsoft YaHei）
 - 数字使用等宽或 Tabular 数字

 ### 6.4 动效
 - 页面切换使用平滑过渡（fade/slide）
 - 卡片列表使用错峰淡入动画（staggered fadeIn）
 - 按钮点击有微小的缩放反馈（scale 0.95）
 - 删除/取消等操作有确认弹窗

 ### 6.5 色彩
 - 保持和桌面端一致的渐变背景氛围
 - 卡片使用毛玻璃效果（backdrop-filter: blur）
 - 主色 #3498db，强调色 #8e44ad
 - 标签颜色沿用数据库中的 color 值

 ### 6.6 状态处理
 - **加载中：** 骨架屏（Skeleton Screen），保持页面结构不跳动
 - **空状态：** 友好的插画 + 引导文案，如「还没有日记，写下第一篇吧~」
 - **错误状态：** Toast 提示，不阻塞用户操作
 - **网络异常：** 离线提示，已加载数据可继续浏览
